# Security Overview

> SAMPLE DATA — NOT LEGAL OR COMPLIANCE ADVICE.

Northstar Cloud is a fictional SaaS provider used by the QuestCite demo. This document describes the sample control narrative used to demonstrate evidence-grounded questionnaire drafting.

## Program and governance

Northstar Cloud maintains a documented information security program with a named security owner, control owners, an annual policy review, and management oversight. The control register records the accountable owner and review cadence for each practice.

Material product and infrastructure changes receive a documented risk review before release. Findings are assigned, prioritized, and tracked through closure with a record of the completed action.

## Assurance and reporting

The fictional service maintains a testing program and incident response process. The current demonstration does not include a customer-shareable penetration-test report or a contractual notification deadline. Those questions remain subject to human review.

Customers can use the security contact published on the Trust Center. Reports are triaged through the incident response process and escalated according to the documented severity criteria.

## Scope note

This policy is a demonstration fixture. It is not an audit report, certification, representation, warranty, or commitment about a real provider.
