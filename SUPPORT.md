# Support policy

WHH Treasures maintains the open-source QuestCite repository. Security and
product reports go to <whhtreasures@gmail.com>. The operator of a deployment
owns the running infrastructure, provider accounts, backups, data retention, and
legal/compliance decisions.

## Included support

The repository includes documentation, reproducible test commands, and a place
to report behavior that differs from the documented version. There is no
response-time service level.

## What to include in a request

Email <whhtreasures@gmail.com> with the version/commit, runtime, safe
reproduction steps, command output with secrets removed, and whether the issue
affects local, hosted-test, or production deployment. Use a private channel for
security reports; see [`SECURITY.md`](SECURITY.md).

Do not send passwords, API keys, raw access tokens, signed URLs, customer
documents, questionnaire answers, prompts, or prospect personal data.

## Boundaries

Transactional email through Resend is optional and configured by each operator.
It is not required for the public demo and is not an included provider account.

Support does not provide legal, audit, privacy, security, or compliance advice.
Generated answers and demo content require human validation before external
use. Provider outages and third-party dashboard configuration remain with the
operator.
